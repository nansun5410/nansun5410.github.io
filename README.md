# Nan Sun — Academic Homepage

A clean, responsive academic homepage inspired by traditional faculty and student homepages. The entire site is static HTML and CSS, with no JavaScript or dependencies.

## Publish to GitHub Pages

1. Create a public GitHub repository named `YOUR_USERNAME.github.io`, replacing `YOUR_USERNAME` with your actual GitHub username.
2. Copy `index.html`, `styles.css`, `favicon.svg`, and the entire `images/` directory to the repository root. You do not need to upload this README.
3. In GitHub, open **Settings → Pages**, choose **Deploy from a branch**, and select `main` / `/(root)` if needed.
4. After GitHub Pages deploys, visit `https://YOUR_USERNAME.github.io/`.

## Edit your information

- `index.html`: biography, technical reports, publications, education, honors, and contact information.
- `styles.css`: spacing, typography, colors, and mobile styles.
- `images/`: the portrait and official figures from paper/project pages. The current portrait has a natural university interior background and a more modest crew-neck layer, based on the provided photo; `images/profile-nan-sun-campus.jpg` is the one used by the site.

The site omits the phone number and earlier employer details. InteractGen's T-RO special-issue conditional-acceptance status was provided by the site owner and may not yet appear on publisher websites. VISTA is omitted pending author-list clarification.
